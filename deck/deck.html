One pipeline, and every step lands in a MariaDB table

A theme is a list of Wikidata items. The same steps run for each article in each language, so a new theme is a new list, not new code.

  1. RevisionsWikipedia API and the Finnish dump, with each edit's original timestamp keptrevision WITH SYSTEM VERSIONING31,461 revisions since 2001
  2. ClaimsCurrent text split into sentences with their citations, embedded by multilingual MiniLMclaim.embedding VECTOR(384)6,747 claims in 68 article versions: fi, sv, en, and de, ru on Winter War
  3. SourcesEach cited page fetched, with an Internet Archive fallback, cut into passages and embeddedsource_chunk VECTOR(384)303 of 1,543 sources read · 20,963 passages
  4. ChecksVEC_DISTANCE_COSINE finds the closest peer sentences and source passages. Gemini 3.8 Flash nominates; Gemini 4 Argon confirms; every quote must match the text exactly.flag80 findings shown

Four checks, in the order an editor can act on them

Counts across all 22 articles. Shown: Winter War, sentences paired across languages by vector search.

  • Wrong fact11 findings
    A date, number or name differs between versions, such as 29 or 28 November.
  • Source4 findings
    The cited page was fetched and read. It does not say this, or says otherwise.
  • Tone3 findings
    Loaded wording in the narrator's voice, such as “continued to lie”, with a neutral rewrite in the same language.
  • Languages62 coverage gaps
    A claim one version has and another lacks. Often a fair difference, so these are grouped and closed by default.

MariaDB does the retrieval and the time travel, live on every page

Vector search
embedding VECTOR(384) NOT NULL, VECTOR INDEX (embedding) M=16 DISTANCE=cosine SELECT … FROM source_chunk ORDER BY VEC_DISTANCE_COSINE(embedding, …) LIMIT 5
  • Pairs each sentence with its closest sentence in the other languages.
  • Finds the passage of the cited page closest to a claim.
  • Retrieves the passages a question in Ask is answered from.

27,710 vectors. Closest source passage 1.4 ms · sentence alignment 2.7 ms · search across every vector 167 ms

System-versioned tables
CREATE TABLE revision (…) WITH SYSTEM VERSIONING SET system_versioning_insert_history=1 SELECT text FROM revision FOR SYSTEM_TIME AS OF '2015-06-01 23:59:59'
  • History is loaded with Wikipedia's own edit times, so “as of” means the real date.
  • The time bar opens an article as it read on a past day. Winter War goes back to 29 Nov 2001.
  • “When this got in” finds the first revision with a sentence's exact wording.

31,461 revisions. An article as of a date, in all its language versions, 5.3 ms

Where it stops today

  • One theme: 22 articles on Finland in the Second World War, of which 7 have findings.
  • 303 of 1,543 cited sources could be read, about 20%. Claims cited to books are marked “not checked”.
  • Test labels come from planted edits. No historian has labelled real findings yet.
  • A coverage gap can be a fair choice for a different audience. A person decides.

It never edits Wikipedia. Try it in 30 seconds.

  1. It flags. A ranked list per theme, then findings per article, the fixable ones first.
  2. It shows the evidence. Exact quotes, the revision, the cited source, and the edit that introduced the wording.
  3. It writes the Talk page note. In the article's own language, with both quotes and links, ready to paste. The editor decides.
