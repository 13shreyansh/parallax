# Parallax design system

The exact authority is DESIGN-DIRECTION.md, supplied for Job 02. It replaces the NPOV Radar visual system. Screens use Operate mode; Method uses Read mode.

White reading surfaces, cool grey chrome, blue-black text. Commissioner is the interface voice. Exact Wikipedia and source quotes use Source Serif 4, roman only. JetBrains Mono appears only in the SQL drawer. Fonts are self-hosted with no swap on first paint. Counts and revision dates use tabular figures.

Four authored markers travel with their check names: red circle for Source, ochre diamond for Languages, purple triangle for Tone, teal square for Wrong fact. Colour appears in the marker, marked words, underline and check label. It never colours a card or primary button. The single primary action uses ink black.

Home is a ranked table. Article is aligned reading columns beside one evidence rail. The same Readings block appears on Home, Article, Ask and Method. Unknown values are explained in editor language. Synthetic test text never enters the product database or public assets.

The time bar is black in the past. Its one authored transition is a 900ms travel to a historical date. Motion becomes instant under reduced-motion preferences. Keyboard shortcuts, visible focus, selection colours and responsive sheets follow the binding direction.
